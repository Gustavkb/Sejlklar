# Sejlklar

Simpel React Native-app til sejlere: en tjekliste før afsejling og en liste
over vigtige kontakter.

## Funktioner

- **Side 1**: sejlklar tjekliste.
- **Side 2**: tilføj nyt punkt til tjekliste.
- **Side 3**: nødvendige kontakter.

- **Tjekliste**: tryk på et punkt for at markere det som udført. Tilføj
  egne punkter via "+ Tilføj punkt".
- **Kontakter**: liste over vigtige numre. Tryk "Ring" for at åbne
  telefonens opkalds-app direkte med nummeret.

## Kom i gang

Dette er et Expo-projekt.

```bash
npm install
npx expo start
```

Scan QR-koden med Expo Go-appen på din telefon, eller tryk `i` i
terminalen for at åbne i iOS-simulator.
